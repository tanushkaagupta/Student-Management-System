# StudentHub REST API Documentation

This document describes the complete REST API specification for the **Student Management System (StudentHub)** backend built with **FastAPI**, **SQLAlchemy**, and **Pydantic**.

---

## Base URL & Interactive Docs

- **Local Base URL**: `http://127.0.0.1:8000`
- **Interactive Swagger UI**: `http://127.0.0.1:8000/docs`
- **Interactive ReDoc**: `http://127.0.0.1:8000/redoc`
- **OpenAPI Schema JSON**: `http://127.0.0.1:8000/openapi.json`

---

## Authentication & Headers

Currently, the API endpoints are public (no authentication headers required). All JSON request bodies must include:
```http
Content-Type: application/json
```

---

## Data Models & Validation Rules

### Student Data Fields

| Field | Type | Required | Description | Constraints / Validation |
|---|---|---|---|---|
| `student_id` | String | Yes (on Create) | Unique identifier for the student | Non-empty string (e.g. `"STU025"`) |
| `full_name` | String | Yes (on Create) | Student's full legal name | Minimum 1 character |
| `date_of_birth` | Date | Yes (on Create) | Date of birth | ISO 8601 format (`YYYY-MM-DD`) |
| `email` | String | Optional | Student's contact email address | Valid email format (RFC standard) |
| `phone` | String | Optional | Student's contact telephone number | String format |
| `address` | String | Optional | Student's residential address | String format |
| `id` | Integer | Auto (Read-only)| Database primary key | Generated by SQLite |
| `created_at` | DateTime | Auto (Read-only)| Timestamp of record creation | UTC ISO timestamp |
| `updated_at` | DateTime | Auto (Read-only)| Timestamp of last update | UTC ISO timestamp |

> **Validation Constraint**: At least one contact method (`email` or `phone`) must be supplied when creating a student record. If neither is provided, the API rejects the request with HTTP `422 Unprocessable Entity`.

## Endpoints

### 1. Root & Health Check

#### `GET /`
Returns API service status message.

- **Response `200 OK`**:
```json
{
  "message": "StudentHub API is running"
}
```

#### `GET /health`
Liveness probe for deployment and monitoring.

- **Response `200 OK`**:
```json
{
  "status": "ok"
}
```

### 2. Student Management (`/students`)

#### `POST /students/`
Creates a new student record.

- **Status Code**: `201 Created`
- **Request Body**:
```json
{
  "student_id": "STU025",
  "full_name": "Riya Sen",
  "date_of_birth": "2004-05-14",
  "email": "riya.sen@example.com",
  "phone": "+91 98765 12345",
  "address": "45 Park Lane, Kolkata"
}
```

- **Response `201 Created`**:
```json
{
  "student_id": "STU025",
  "full_name": "Riya Sen",
  "date_of_birth": "2004-05-14",
  "email": "riya.sen@example.com",
  "phone": "+91 98765 12345",
  "address": "45 Park Lane, Kolkata",
  "id": 1,
  "created_at": "2026-10-15T18:00:00Z",
  "updated_at": null
}
```

- **Error Responses**:
  - `409 Conflict`: If `student_id` already exists in the database.
    ```json
    { "detail": "Student ID already exists" }
    ```
  - `422 Unprocessable Entity`: If validation fails (e.g., missing required fields, invalid email format, or both `email` and `phone` are omitted).
    ```json
    {
      "detail": [
        {
          "loc": ["body"],
          "msg": "Value error, At least one of email or phone must be provided",
          "type": "value_error"
        }
      ]
    }
    ```

---

#### `GET /students/`
Retrieves a paginated list of students with optional search filter.

- **Query Parameters**:
  - `skip` (integer, default: `0`): Number of records to skip for pagination.
  - `limit` (integer, default: `100`): Maximum number of records to return.
  - `search` (string, optional): Case-insensitive search term matched against `full_name`, `student_id`, or `email`.

- **Example Request**:
```http
GET /students/?search=Riya&limit=10 HTTP/1.1
Host: 127.0.0.1:8000
```

- **Response `200 OK`**:
```json
[
  {
    "student_id": "STU025",
    "full_name": "Riya Sen",
    "date_of_birth": "2004-05-14",
    "email": "riya.sen@example.com",
    "phone": "+91 98765 12345",
    "address": "45 Park Lane, Kolkata",
    "id": 1,
    "created_at": "2026-10-15T18:00:00Z",
    "updated_at": null
  }
]
```

---

#### `GET /students/{student_id}`
Retrieves a single student by their unique `student_id`.

- **Path Parameter**:
  - `student_id` (string): The identifier of the student (e.g. `STU025`).

- **Response `200 OK`**:
```json
{
  "student_id": "STU025",
  "full_name": "Riya Sen",
  "date_of_birth": "2004-05-14",
  "email": "riya.sen@example.com",
  "phone": "+91 98765 12345",
  "address": "45 Park Lane, Kolkata",
  "id": 1,
  "created_at": "2026-10-15T18:00:00Z",
  "updated_at": null
}
```

- **Error Responses**:
  - `404 Not Found`: When the student ID does not exist.
    ```json
    { "detail": "Student not found" }
    ```

---

#### `PUT /students/{student_id}`
Updates details for an existing student. Accepts partial update payloads.

- **Path Parameter**:
  - `student_id` (string): Target student ID.

- **Request Body** (provide only fields to update):
```json
{
  "full_name": "Riya Sen-Sharma",
  "phone": "+91 98765 99999"
}
```

- **Response `200 OK`**:
```json
{
  "student_id": "STU025",
  "full_name": "Riya Sen-Sharma",
  "date_of_birth": "2004-05-14",
  "email": "riya.sen@example.com",
  "phone": "+91 98765 99999",
  "address": "45 Park Lane, Kolkata",
  "id": 1,
  "created_at": "2026-10-15T18:00:00Z",
  "updated_at": "2026-10-15T18:30:00Z"
}
```

- **Error Responses**:
  - `404 Not Found`: If target student is not found.
  - `422 Unprocessable Entity`: If invalid types or invalid email are supplied.

---

#### `DELETE /students/{student_id}`
Permanently deletes a student record from the database.

- **Path Parameter**:
  - `student_id` (string): Target student ID.

- **Response `204 No Content`** (Empty body).

- **Error Responses**:
  - `404 Not Found`: If student is not found.
    ```json
    { "detail": "Student not found" }
    ```
